## About the course

Copilot, Microsoft's AI assistant built into the Power Platform, lets you create a working canvas app from a plain-English prompt, design screens and data tables conversationally, and generate Power Fx formulas without memorising syntax. You start by enabling Copilot in Power Apps Studio and preparing well-described Dataverse data, then learn the prompting techniques that turn a business requirement into a functional app.

The course then goes deeper into AI-assisted app development: refining screens, controls and data with Copilot, adding an in-app Copilot chat for your users, and using Copilot in Power Automate to build the approval and notification flows that power your app — finishing with sharing and governing the result responsibly.

## Learning outcomes

By the end of the course, you will be able to:

1. Enable Copilot in Power Apps and navigate Power Apps Studio ready to build.
2. Prepare a Dataverse table with clear names and descriptions so Copilot can build accurate apps.
3. Write effective prompts that get Copilot to build the app you actually want.
4. Create a working canvas app from a single plain-language prompt.
5. Refine an app's screens, controls and layouts by describing the changes to Copilot.
6. Generate and explain Power Fx formulas with Copilot, and verify them against your data.
7. Add an in-app Copilot chat so end users can query the app's data in natural language.
8. Build a Power Automate flow with Copilot and call it from a canvas app.
9. Automate approval and notification scenarios with Copilot-built flows.
10. Share and govern AI-assisted apps responsibly.

## Topics covered

- **Topic 1 — Get Started with Copilot in Power Apps:** Copilot and the Power Platform; licensing, requirements and enabling Copilot; Copilot in Power Apps Studio; effective prompting for app building; preparing data with Dataverse.
- **Topic 2 — Build Canvas Apps with Copilot:** creating an app from a prompt; refining screens, controls and layouts; generating and explaining Power Fx formulas; adding an in-app Copilot chat.
- **Topic 3 — Automate and Extend with Copilot:** building Power Automate flows with Copilot; integrating flows with canvas apps; approval and notification scenarios; sharing and governing AI-assisted apps.

## Lab Activities

The 10 labs form one connected practical journey. Complete them in order so each verified output can support the activities that follow.

| # | Activity | Outcome |
|---:|----------|---------|
| **1** | [Enable Copilot and Get Oriented in Power Apps Studio](labs/lab-01-enable-copilot-and-get-oriented-in-power-apps-studio.md) | Sign in to Power Apps, confirm Copilot is enabled, and find your way around Power Apps Studio and the Copilot pane. |
| **2** | [Prepare Your Data with Dataverse for Copilot](labs/lab-02-prepare-your-data-with-dataverse-for-copilot.md) | Create a well-described Dataverse table so Copilot has the context it needs to build an accurate app. |
| **3** | [Write Effective Prompts for App Building](labs/lab-03-write-effective-prompts-for-app-building.md) | Compare a vague app prompt with a specific one and capture a reusable four-part prompt pattern for building apps. |
| **4** | [Create a Canvas App from a Prompt](labs/lab-04-create-a-canvas-app-from-a-prompt.md) | Generate a working, multi-screen canvas app from a single plain-language prompt grounded on your Dataverse table. |
| **5** | [Refine Screens, Controls and Layouts with Copilot](labs/lab-05-refine-screens-controls-and-layouts-with-copilot.md) | Improve the generated app's screens, controls and layout by describing the changes to Copilot in plain language. |
| **6** | [Generate and Explain Power Fx Formulas with Copilot](labs/lab-06-generate-and-explain-power-fx-formulas-with-copilot.md) | Use Copilot to write Power Fx formulas from a description, explain existing formulas, and verify them against your data. |
| **7** | [Add an In-App Copilot Chat for Users](labs/lab-07-add-an-in-app-copilot-chat-for-users.md) | Add a Copilot chat control so end users can ask questions of the app's data in natural language. |
| **8** | [Build a Power Automate Flow with Copilot and Call It from the App](labs/lab-08-build-a-power-automate-flow-with-copilot-and-call-it-from-the-app.md) | Use Copilot to build an automated flow, then integrate it with the canvas app so a button starts the automation. |
| **9** | [Automate Approval and Notification Scenarios](labs/lab-09-automate-approval-and-notification-scenarios.md) | Extend the flow into an approval-and-notification scenario that updates the request based on the decision. |
| **10** | [Share and Govern Your AI-Assisted App](labs/lab-10-share-and-govern-your-ai-assisted-app.md) | Share the app and flow with the right people and apply sensible governance to your AI-assisted solution. |

## About

This repository contains the complete lab and courseware package for **Copilot for Power Apps** (**C803**) by Tertiary Courses / Tertiary Infotech. The practical activities build progressively from **Enable Copilot and Get Oriented in Power Apps Studio** to **Share and Govern Your AI-Assisted App**, with explicit checks that help learners verify each result before moving on.

### What you'll learn

- Complete **10 connected hands-on activities** and carry their outputs through one coherent learning journey.
- Practise with **Microsoft Copilot · Power Apps · Power Automate · Microsoft Dataverse · Microsoft Outlook** and the supporting resources supplied in the repository.
- Begin with **Enable Copilot and Get Oriented in Power Apps Studio** and finish with **Share and Govern Your AI-Assisted App**.
- Apply safe data handling, evidence checks and named human review before using AI-generated or automated outputs.

## Getting Started

### Prerequisites

- The accounts and software required for **Microsoft Copilot · Power Apps · Power Automate · Microsoft Dataverse · Microsoft Outlook**. Follow the setup and access notes in each lab.
- Review [`labs/tools.md`](labs/tools.md) before class for environment, account and safe-use requirements.
- A modern web browser and Git for cloning the materials.
- Synthetic or authorised data only. Do not place secrets, personal data or confidential material into an unapproved service.
- A named human reviewer for facts, calculations, decisions and any externally released output.

### 1. Clone the repository

```bash
git clone https://github.com/tertiarycourses/C803---Copilot-for-Power-Apps.git
cd C803---Copilot-for-Power-Apps
```

### 2. Open the lab index

Start with [labs/README.md](labs/README.md), then complete Labs 1–10 in order. Each lab provides the activity context, practical steps and a way to verify the result.

### 3. Keep your connected outputs

Store each lab output in the suggested working folder and retain the evidence or review notes requested by the lab. Later activities depend on these approved outputs.
